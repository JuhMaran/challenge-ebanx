# Desafio EBANX

Projeto desenvolvido para o desafio técnico utilizando Spring Boot.

## Tecnologias Utilizadas

* Java 25
* Spring Boot 4
* Spring Framework 7
* Maven
* Lombok

## Executando a Aplicação

```bash
mvn spring-boot:run
```

## Executando os testes

```bash
mvn test
```
